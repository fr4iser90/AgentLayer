# Private dashboard kinds (local machine only)

Board JSON under this folder is **gitignored** except this README.

On a machine that has the private kinds (`knowledge`, `hygiene`, `crisis`, `bga`,
`icu`, `meds`, `abx`), open **Dashboards** → create/install those kinds.

Public AgentLayer only adds a generic **`formula_calc`** block type. Clinic layouts
and demo checklists stay here — not in the public remote.

See local planning: `docs/planning/knowledge-companion/verticals/_private/clinic-web-surface.md`.
